# Teste de aceitação V20.3

## Antes de testar

1. Execute `bun install`.
2. Execute `bun run lint`.
3. Execute `bun run build`.
4. Execute `bun run dev`.
5. Abra o aplicativo em celular ou no modo responsivo do navegador.

## Início

- [ ] O cabeçalho mostra `BAFAFEED`.
- [ ] A saudação não usa `Ô`.
- [ ] A saudação inclui o primeiro nome do cliente.
- [ ] Um novo login pode selecionar outra saudação.
- [ ] O endereço não aparece no cabeçalho do Início.
- [ ] A logo aparece como uma placa.
- [ ] Novidades aparecem em laranja com textura xadrez.
- [ ] Promoções gerais aparecem em amarelo.
- [ ] Missões aparecem em turquesa.
- [ ] Check-in aparece em verde.
- [ ] A chamada para a Resenha aparece em roxo.
- [ ] A chamada para completar o Perfil aparece em azul.

## Fofoquinhas

- [ ] Fofoquinhas liberadas usam o padrão amarelo.
- [ ] Missões usam o padrão turquesa.
- [ ] Ativação, QR e links externos continuam funcionando.
- [ ] Os modais mantêm boa leitura e não ultrapassam a tela.

## Resenha

- [ ] O cabeçalho usa o padrão roxo noturno.
- [ ] A sala tem identidade visual própria.
- [ ] Mensagens próprias e de outras pessoas são facilmente diferenciadas.
- [ ] Envio, resposta, denúncia, bloqueio e salves continuam funcionando.
- [ ] Estados fechado, aguardando, aberto e encerrado continuam corretos.
- [ ] A tela continua utilizável com teclado aberto no celular.

## Perfil

- [ ] A carteirinha usa o padrão azul.
- [ ] Os campos suspensos têm seta e foco visíveis.
- [ ] Os controles de privacidade continuam alterando o estado corretamente.
- [ ] Salvar perfil continua funcionando.
- [ ] Perfil público, segurança e pessoas bloqueadas continuam acessíveis.

## Navegação

- [ ] Início usa amarelo.
- [ ] Fofoquinhas usa laranja.
- [ ] Resenha usa roxo.
- [ ] Perfil usa azul.
- [ ] Todas as rotas continuam iguais às da V20.2.
